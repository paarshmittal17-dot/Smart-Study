# Project Statement

## Title
SmartStudy — Personalized Study Time Optimizer

## Problem Statement
First-year students often study several subjects while having limited weekly study time. They may not know how to divide that time according to marks, subject difficulty, attendance and examination urgency.

SmartStudy solves this problem with a Python program. It collects academic information, calculates a priority score for each subject, and distributes available study hours accordingly. It also generates a simple daily study plan.

## Objectives
1. Collect and validate student data.
2. Calculate grades and overall average.
3. Identify subjects requiring more attention.
4. Calculate subject priority using a rule-based algorithm.
5. Consider marks, difficulty, attendance and exam urgency.
6. Allocate weekly study hours.
7. Generate a daily study schedule.
8. Allow records to be updated and deleted.
9. Save data in JSON and export analysis to CSV.
10. Demonstrate Python Essentials concepts.

## Target Users
- First-year college students
- School students
- Students preparing for examinations

## Functional Requirements
- Student profile creation
- Subject CRUD operations
- Performance analysis
- Priority calculation
- Study-plan generation
- Data persistence
- CSV reporting
- Input validation

## Non-Functional Requirements
- Usability: menu-driven and beginner-friendly.
- Reliability: invalid numeric inputs are rejected.
- Maintainability: functions are separated into modules.
- Performance: calculations are lightweight and run locally.
- Error handling: invalid input and corrupted saved data are handled.

## Scope
This is a rule-based educational planning program. It does not use machine learning, external APIs, cloud services or advanced frameworks.
